PAUSECUT DESKTOP PARA WINDOWS 10/11 (64 BITS)
================================================

1. Extraia todo o conteúdo do ZIP para uma pasta.
2. Abra PauseCut.Desktop.exe.
3. Se o Windows exibir uma proteção por o aplicativo não estar assinado,
   confira a origem e o SHA-256 publicado no site antes de continuar.

O aplicativo abre em uma janela dedicada do Microsoft Edge ou Google Chrome.
Ao fechar essa janela, o motor local também é encerrado.

DESEMPENHO
-----------
- O FFmpeg incluído é nativo de 64 bits.
- O PauseCut testa automaticamente NVIDIA NVENC, Intel Quick Sync e AMD AMF.
- Se nenhuma GPU compatível estiver disponível, usa a CPU nativa com todos os
  processadores lógicos detectados.
- O vídeo não é enviado para a internet.

ARQUIVOS TEMPORÁRIOS E LOG
--------------------------
Dados temporários: %LOCALAPPDATA%\PauseCut\data
Log de diagnóstico: %LOCALAPPDATA%\PauseCut\logs\desktop.log

Os trabalhos antigos são limpos na próxima inicialização. Mantenha o original
e baixe o resultado antes de fechar o aplicativo.

REQUISITOS
----------
- Windows 10 ou Windows 11, 64 bits.
- Microsoft Edge ou Google Chrome para a janela do aplicativo.
- Espaço livre suficiente para o vídeo original, os temporários e a saída.
- Drivers atualizados para usar aceleração por GPU.

Não é necessário instalar .NET nem FFmpeg.
